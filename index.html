Antes de escribir código, dejamos listo todo lo necesario para trabajar sin errores de entorno.

1

Instalar todo desde cero

Editor, Node.js, npm y Angular CLI.

ObjetivoQue los comandos node, npm y ng funcionen.
NecesitasWindows, macOS o Linux y acceso a Internet.
ResultadoUna terminal preparada para crear proyectos Angular.

1.1 Instala Visual Studio Code

Visual Studio Code será el editor donde abrirás las carpetas y modificarás los archivos. No es obligatorio para Angular, pero es una opción sencilla para principiantes.

1
Descarga Visual Studio Code desde su sitio oficial e instálalo.
2
Ábrelo una vez para comprobar que funciona.
3
En Extensions puedes instalar Angular Language Service. Ayuda con autocompletado y errores en templates.

1.2 Instala Node.js

Node.js permite ejecutar herramientas JavaScript fuera del navegador. Angular CLI necesita Node.js para funcionar. npm se instala junto con Node.js y sirve para instalar paquetes.

Versión recomendada para este taller: Node.js 24 LTS. Angular 22 admite Node ^22.22.3, ^24.15.0 o ^26.0.0. Para estudiantes conviene una rama LTS, no una versión experimental.

1.3 Comprueba Node y npm

Abre PowerShell, CMD o la terminal integrada de VS Code y escribe:

Terminal
node -v
npm -v
Debes ver: dos números de versión. Por ejemplo v24.x.x para Node y un número de npm debajo.
Si aparece “node no se reconoce”: Node no quedó instalado correctamente o la terminal estaba abierta antes de instalarlo. Cierra y vuelve a abrir la terminal.

1.4 Instala Angular CLI

CLI significa Command Line Interface. Es la herramienta que crea proyectos, componentes y servicios Angular mediante comandos.

Terminal
npm install -g @angular/cli
npm
Administrador de paquetes de Node.js.
install
Indica que vamos a instalar un paquete.
-g
Instala la herramienta globalmente para poder usar ng desde cualquier carpeta.
@angular/cli
Nombre oficial del paquete Angular CLI.

1.5 Problema frecuente en Windows PowerShell

Si PowerShell muestra un error parecido a “la ejecución de scripts está deshabilitada”, Angular documenta esta solución:

PowerShell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

Lee el mensaje de PowerShell antes de confirmar. El cambio afecta la política de ejecución del usuario actual.

1.6 Comprueba Angular

Terminal
ng version
Debes ver: Angular CLI, Node, npm y el sistema operativo. Si ng version funciona, el entorno está listo.
Conceptos que ya debes distinguir
Node.js: ejecuta herramientas JavaScript fuera del navegador.
npm: instala dependencias.
Angular CLI: crea y administra proyectos Angular.
VS Code: editor de archivos; no ejecuta Angular por sí solo.

Antes de continuar

Ejecuta node -v, npm -v y ng version. Los tres deben responder correctamente.

const lista = document.querySelector('#listaEstudiantes');
const total = document.querySelector('#totalEstudiantes');

function renderizarEstudiantes(datos) {
  lista.innerHTML = '';

  for (const estudiante of datos) {
    lista.innerHTML +=
      '<article class="estudiante">' +
        '<div>' +
          '<h3>' + estudiante.nombre + '</h3>' +
          '<p>' + estudiante.programa + ' · semestre ' + estudiante.semestre + '</p>' +
          '<p>' + estudiante.email + '</p>' +
        '</div>' +
        '<button class="btn-eliminar" data-id="' + estudiante.id + '">Eliminar</button>' +
      '</article>';
  }

  total.textContent = estudiantes.length;
}

renderizarEstudiantes(estudiantes);

textContent
Cambia únicamente el texto de un elemento.

Eventos: hacer funcionar la búsqueda

Evento input 
buscar.addEventListener('input', function () {
  const texto = buscar.value.toLowerCase().trim();

  const filtrados = estudiantes.filter(function (estudiante) {
    return estudiante.nombre.toLowerCase().includes(texto) ||
           estudiante.programa.toLowerCase().includes(texto);
  });

  renderizarEstudiantes(filtrados);
});

'input'

filter()
Crea un nuevo array con los elementos que cumplen una condición.
includes()
Comprueba si un texto contiene otro.
toLowerCase()
Evita que mayúsculas/minúsculas rompan la búsqueda.

Formulario: agregar y eliminar estudiantes

Angular Aula ya empieza a comportarse como una aplicación CRUD.

Agrega la referencia al formulario:

app.js 
const formulario = document.querySelector('#formEstudiante');

10.1 Agregar

Evento submit 
formulario.addEventListener('submit', function (evento) {
  evento.preventDefault();

  const nuevo = {
    id: Date.now(),
    nombre: formulario.nombre.value.trim(),
    email: formulario.email.value.trim(),
    programa: formulario.programa.value.trim(),
    semestre: Number(formulario.semestre.value)
  };

  estudiantes.push(nuevo);
  formulario.reset();
  renderizarEstudiantes(estudiantes);
});
preventDefault(): evita que el formulario recargue la página. Date.now(): nos da un número que usaremos como ID sencillo. push(): agrega al final del array.

10.2 Eliminar

Delegación de evento 
lista.addEventListener('click', function (evento) {
  if (!evento.target.classList.contains('btn-eliminar')) {
    return;
  }

  const id = Number(evento.target.dataset.id);

  estudiantes = estudiantes.filter(function (estudiante) {
    return estudiante.id !== id;
  });

  renderizarEstudiantes(estudiantes);
});

Guardar los datos con localStorage

Hasta ahora todo desaparece al recargar. Vamos a persistirlo.

11.1 Crea funciones de guardar y leer

app.js 
const CLAVE = 'angular-aula-estudiantes';

function guardarEstudiantes() {
  localStorage.setItem(CLAVE, JSON.stringify(estudiantes));
}

function leerEstudiantes() {
  const guardados = localStorage.getItem(CLAVE);

  if (guardados) {
    estudiantes = JSON.parse(guardados);
  }
}

Consumir una API con fetch, async y await

El botón “Importar desde API” finalmente tendrá una función.

Agrega referencias:

app.js
const btnImportar = document.querySelector('#btnImportar');
const estadoApi = document.querySelector('#estadoApi');

Y luego la función:

app.js · API 
async function importarUsuarios() {
  estadoApi.textContent = 'Cargando usuarios...';

  try {
    const respuesta = await fetch('https://jsonplaceholder.typicode.com/users');

    if (!respuesta.ok) {
      throw new Error('HTTP ' + respuesta.status);
    }

    const usuarios = await respuesta.json();

    const importados = usuarios.slice(0, 5).map(function (usuario) {
      return {
        id: Date.now() + usuario.id,
        nombre: usuario.name,
        email: usuario.email,
        programa: 'Importado desde API',
        semestre: 1
      };
    });

    estudiantes = estudiantes.concat(importados);

    guardarEstudiantes();
    renderizarEstudiantes(estudiantes);

    estadoApi.textContent = 'Usuarios importados correctamente.';
  } catch (error) {
    console.error(error);
    estadoApi.textContent = 'No fue posible consultar la API.';
  }
}

btnImportar.addEventListener('click', importarUsuarios);
async
Permite usar await dentro de la función.
fetch(url)
Realiza una petición HTTP.
await
Espera a que termine una operación asíncrona.
respuesta.ok
Indica si HTTP respondió correctamente.
respuesta.json()
Convierte el cuerpo JSON en objetos JavaScript.
try/catch
Permite reaccionar ante errores de red o ejecución.

TypeScript: tipar el mismo modelo Estudiante

No cambiamos de problema; describimos con más precisión los datos que ya conocemos.

JavaScript
let semestre = 4;

La variable existe, pero el lenguaje no declara explícitamente su tipo.

→
TypeScript
let semestre: number = 4;

Indicamos que debe contener un número.

13.1 Interface

Modelo TypeScript 
interface Estudiante {
  id: number;
  nombre: string;
  email: string;
  programa: string;
  semestre: number;
  externo?: boolean;
}

? significa que la propiedad es opcional.

13.2 Array tipado

TypeScript
let estudiantes: Estudiante[] = [];

13.3 Función tipada

TypeScript
function eliminar(id: number): void {
  estudiantes = estudiantes.filter(estudiante => estudiante.id !== id);
}
id: number
El parámetro debe ser un número.
: void
La función no devuelve un valor.
Estudiante[]
Array cuyos elementos deben respetar la interface.

Comprobación

Debes distinguir string, number, boolean, interface, array y parámetro de función.

Crear un servicio para el estado y localStorage

Las páginas no deberían duplicar la lógica de datos.

Terminal

estudiantes.ts 
import { computed, Injectable, signal } from '@angular/core';
import { Estudiante } from '../models/estudiante';

@Injectable({
  providedIn: 'root'
})
export class Estudiantes {
  private readonly clave = 'angular-aula-estudiantes';

  private readonly _estudiantes =
    signal<Estudiante[]>(this.leer());

  readonly estudiantes = this._estudiantes.asReadonly();

  readonly total =
    computed(() => this._estudiantes().length);

  agregar(datos: Omit<Estudiante, 'id'>): void {
    const nuevo: Estudiante = {
      id: Date.now(),
      ...datos
    };

    this._estudiantes.update(actuales => [
      ...actuales,
      nuevo
    ]);

    this.guardar();
  }

  eliminar(id: number): void {
    this._estudiantes.update(actuales =>
      actuales.filter(estudiante => estudiante.id !== id)
    );

    this.guardar();
  }

  agregarVarios(nuevos: Estudiante[]): void {
    this._estudiantes.update(actuales => [
      ...actuales,
      ...nuevos
    ]);

    this.guardar();
  }

  private guardar(): void {
    localStorage.setItem(
      this.clave,
      JSON.stringify(this._estudiantes())
    );
  }

  private leer(): Estudiante[] {
    const guardados = localStorage.getItem(this.clave);

    if (guardados) {
      return JSON.parse(guardados);
    }

    return [
      {
        id: 1,
        nombre: 'Ana Torres',
        email: 'ana@correo.com',
        programa: 'Ingeniería de Sistemas',
        semestre: 4
      },
      {
        id: 2,
        nombre: 'Carlos Ruiz',
        email: 'carlos@correo.com',
        programa: 'Diseño',
        semestre: 2
      }
    ];
  }
}
@Injectable
Permite que Angular gestione la creación/inyección del servicio.
providedIn: 'root'
Hace que exista una instancia compartida a nivel de aplicación.
private
La propiedad solo se usa dentro del servicio.
asReadonly()
Expone el Signal para lectura sin permitir que otros lo modifiquen directamente.
update()
Calcula un nuevo valor a partir del estado actual.
Resultado: agregar/eliminar/persistir dejan de pertenecer al componente raíz y pasan al servicio.
