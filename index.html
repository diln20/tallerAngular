¿Qué es Angular y para qué sirve?

Angular organiza una aplicación web grande en piezas pequeñas y coordinadas.

Sin un framework, tú debes decidir manualmente cómo organizar pantallas, actualizar datos, navegar entre vistas y comunicarte con un servidor. Angular te da una estructura y herramientas para esas tareas.

Framework

Un conjunto de reglas y herramientas para construir aplicaciones de forma organizada.

SPA

Single Page Application: la interfaz cambia sin recargar una página HTML completa en cada navegación.

Componente

Una pieza visual reutilizable: barra, tarjeta, formulario, pantalla, etc.

Idea clave: Angular no reemplaza HTML, CSS y JavaScript. Los organiza y añade herramientas encima de ellos.

7

Datos que cambian: signals, propiedades y eventos

La interfaz deja de ser estática cuando el usuario puede cambiar el estado.

Signals en una frase

Un signal guarda un valor que Angular puede observar. Si cambia, Angular actualiza automáticamente las partes de la pantalla que lo leen.

src/app/app.ts
app.ts
import { Component, signal } from '@angular/core';
import { RouterOutlet } from '@angular/router';

@Component({
  selector: 'app-root',
  imports: [RouterOutlet],
  templateUrl: './app.html',
  styleUrl: './app.css'
})
export class App {
  titulo = 'Angular Aula';
  contador = signal(0);

  aumentar(): void {
    this.contador.update(valor => valor + 1);
  }

  reiniciar(): void {
    this.contador.set(0);
  }
}
src/app/app.html
app.html
<main class="contenedor">
  <h1>{{ titulo }}</h1>
  <p>Participaciones: {{ contador() }}</p>

  <button (click)="aumentar()">Sumar participación</button>
  <button (click)="reiniciar()">Reiniciar</button>
</main>

{{ }}

Interpolación: muestra un valor.

[propiedad]

Property binding: envía un valor a una propiedad.

(evento)

Event binding: ejecuta algo cuando sucede un evento.

Ejemplo de property binding

app.html
<button [disabled]="contador() === 0" (click)="reiniciar()">
  Reiniciar
</button>

Mostrar listas y tomar decisiones con @if y @for

Ahora nuestra app tendrá muchos estudiantes, no una tarjeta escrita manualmente.

src/app/app.ts
app.ts · dentro de App
estudiantes = [
  { id: 1, nombre: 'Ana', programa: 'Sistemas', activo: true },
  { id: 2, nombre: 'Luis', programa: 'Diseño', activo: true },
  { id: 3, nombre: 'Marta', programa: 'Sistemas', activo: false }
];
src/app/app.html
app.html
<section>
  <h2>Estudiantes</h2>

  @for (estudiante of estudiantes; track estudiante.id) {
    <app-estudiante-card
      [nombre]="estudiante.nombre"
      [programa]="estudiante.programa"
    />
  } @empty {
    <p>No hay estudiantes registrados.</p>
  }
</section>

Cuando pasas una variable, usa corchetes: [nombre]="estudiante.nombre". Sin corchetes, Angular recibiría literalmente el texto estudiante.nombre.

Condición con @if

estudiante-card.html · ejemplo
@if (activo()) {
  <span class="estado activo">Activo</span>
} @else {
  <span class="estado inactivo">Inactivo</span>
}
¿Por qué existe track? Le dice a Angular cómo identificar cada elemento de la lista para actualizar solo lo necesario. Una propiedad única como id es una buena opción.

2. Variables y método

app.ts · dentro de App
nuevoNombre = '';
nuevoPrograma = '';

agregarEstudiante(): void {
  if (!this.nuevoNombre.trim()) return;

  const nuevo = {
    id: Date.now(),
    nombre: this.nuevoNombre,
    programa: this.nuevoPrograma || 'Sin programa',
    activo: true
  };

  this.estudiantes.push(nuevo);
  this.nuevoNombre = '';
  this.nuevoPrograma = '';
}

      required
    />
  </label>

  <label>

    <input
      name="programa"
      [(ngModel)]="nuevoPrograma"
    />

</form>
[(ngModel)] es enlace en dos direcciones: el input modifica la variable y, si la variable cambia desde TypeScript, el input también puede reflejarlo.

Es una forma de comunicación entre programas. Tu aplicación Angular puede pedir datos a un servidor mediante HTTP.

Crear servicio

Terminal
ng g service services/usuarios
src/app/services/usuarios.ts
usuarios.ts
import { inject, Injectable } from '@angular/core';
import { HttpClient } from '@angular/common/http';

export interface Usuario {
  id: number;
  name: string;
  email: string;
}

@Injectable({ providedIn: 'root' })
export class Usuarios {
  private http = inject(HttpClient);
  private url = 'https://jsonplaceholder.typicode.com/users';

  obtenerUsuarios() {
    return this.http.get<Usuario[]>(this.url);
  }
}
Angular 21+: HttpClient está disponible para inyección por defecto. También puedes usar provideHttpClient() en app.config.ts cuando necesites configurar características como interceptores.

Usar el servicio en una página

src/app/pages/estudiantes/estudiantes.ts
estudiantes.ts
import { Component, inject, signal } from '@angular/core';
import { Usuario, Usuarios } from '../../services/usuarios';

@Component({
  selector: 'app-estudiantes',
  imports: [],
  templateUrl: './estudiantes.html',
  styleUrl: './estudiantes.css'
})
export class Estudiantes {
  private usuariosService = inject(Usuarios);
  usuarios = signal<Usuario[]>([]);
  cargando = signal(false);
  error = signal('');

  cargar(): void {
    this.cargando.set(true);
    this.error.set('');

    this.usuariosService.obtenerUsuarios().subscribe({
      next: datos => {
        this.usuarios.set(datos);
        this.cargando.set(false);
      },
      error: () => {
        this.error.set('No fue posible cargar los usuarios');
        this.cargando.set(false);
      }
    });
  }
}
src/app/pages/estudiantes/estudiantes.html
estudiantes.html
<button (click)="cargar()">Cargar usuarios</button>

@if (cargando()) {
  <p>Cargando...</p>
}

@if (error()) {
  <p>{{ error() }}</p>
}

@for (usuario of usuarios(); track usuario.id) {
  <article>
    <h3>{{ usuario.name }}</h3>
    <p>{{ usuario.email }}</p>
  </article>
}
¿Por qué subscribe()? HttpClient devuelve un Observable. La petición se envía cuando te suscribes; luego recibes el resultado o un error.
